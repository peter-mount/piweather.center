\subsectionfit{Calculate For}
\label{config:calculateFor}
\index{calculate for}
\index{Config!calculate for}

\begin{lstlisting}[language=Go,style=kaolstplain]
calculate for ...
\end{lstlisting}

\Statement{calculate for} defines a calculation to be performed at either regular intervals or whenever one or more
metrics change value.

\paragraph{every}defines when the calculation should be performed over time.
This is usually used for periodic calculations that do not depend on metrics.
For example calculating the Sun's altitude at the weather station.
