\chapter{Configuration}
\labch{configuration}

The main configuration of the various applications is done by a series of configuration files, one for each application.
These files, however, follow the same syntax, so this section defines that common syntax.

\begin{lstlisting}[caption={Example configuration file},language=Go]
// Configuration example showing the portion that is common to all
// configuration files
station( "tower"
    location( "Tower of London" "51.511380329" "-0.0777891" 34 )
    timezone( "Europe/London" )

    // Configuration specific entries here
)
\end{lstlisting}

\paragraph{Comments} can be included in the configuration files by using \SyntaxDefinition{//}

\sectionpagedright{Reference}\label{sec:config:reference}

In this section, the following syntax is used for describing the syntax of various statements:

\begin{lstlisting}[language=Go,style=kaolstplain,escapechar=|]
statement( "metric"
    [every "crontab"]
    ( |\textit{value}\dots| )
    [load "when" with "expression"]
    [usefirst "metric"]
    as |\textit{expression}\dots|
)
\end{lstlisting}

\begin{table}[h!]
    \begin{tabular}{l l l}
        \toprule
        Definition & Purpose & Reference \\
        \midrule
        \text{[\,]} & The statements inside are optional} & \\
        (\,) & related configuration, (\,) required} & \\
        \dots & One or more values expected} & \\
        "crontab" & Crontab schedule & \vref{config:crontab}} \\
        "metric" & A named metric & \\
        "timezone" & Time Zone name & \vref{config:timezone}} \\
        "unit" & Unit of measurement & \\
        \textit{expression} & Expression to evaluate & \\
        "expression" & Database Expression & \\
        \bottomrule
    \end{tabular}
\end{table}

Any other type of string is dependent on the individual statement.
