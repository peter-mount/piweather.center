\subsectionfit{Timezone}
\label{config:timezone}
\index{timezone}
\index{Config!timezone}

\begin{lstlisting}[language=Go,style=kaolstplain]
timezone( "name" )
\end{lstlisting}

\Statement{timezone} defines the Time Zone\index{Time Zone} that the weather station operates under.

For example, if the station is within the United Kingdom then Europe/London should be used.

If the \Statement{timezone} statement is not set then UTC is used.
