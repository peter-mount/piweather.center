\sectionpaged{Heat Index}

The heat index\index{Heat Index} is an index that combines air temperature and relative humidity, in shaded areas,
and represents how a human perceives the temperature.
It is only valid for temperatures above \Fahrenheit{80}.

The computation of the heat index is done using the Rothfusz regression\sidesupercite{RothfuszHeatIndex}:

\NewValueUnit{\HeatIndex}{T_{hi}}{Heat Index}
\begin{definition}Heat Index
\begin{eqnarray*}
    \HeatIndex &=& c_1 + c_2\,\AmbientTemperature + c_3\,\RelativeHumidity + c_4\,\AmbientTemperature\,\RelativeHumidity \\
    && + c_5\,\AmbientTemperature^2 + c_6\,\RelativeHumidity^2 + c_7\,\AmbientTemperature^2\,\RelativeHumidity \\
    && + c_8\,\AmbientTemperature\,\RelativeHumidity^2 + c_9\,\AmbientTemperature^2\,\RelativeHumidity^2
\end{eqnarray*}

\WhereDescription{
   \item[\HeatIndex] the \texttt{Heat Index}, in the same unit as \AmbientTemperature.
   \item[\AmbientTemperature] the \texttt{Ambient temperature}\index{Temperature!Ambient}
   \item[\RelativeHumidity] the \texttt{Relative Humidity}\index{Relative Humidity}
}

For the coefficients, use \vreftab{heatIndexCelsius} \AmbientTemperature is in Celsius
or \vreftab{heatIndexFahrenheit} if in Fahrenheit.
\end{definition}

The Rothfusz regression is not appropriate when conditions of temperature and humidity warrant a heat index value below about \Fahrenheit{80}.
In those cases, a simpler formula is applied\sidesupercite{WikiHeatIndex}:
\begin{definition}Simplified Heat Index
\[ \HeatIndex = 61 + \AmbientTemperature + 1.2(\AmbientTemperature - 68) + 0.095\,\RelativeHumidity \]

\end{definition}
